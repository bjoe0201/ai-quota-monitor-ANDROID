## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant ADRs under `docs/adr/` when that directory exists.
- If either location is absent, proceed silently.

Use the vocabulary defined in `CONTEXT.md`. If proposed work conflicts with an ADR, surface the conflict explicitly instead of silently overriding it.
